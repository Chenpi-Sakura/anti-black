## 1. 背景与目标

### 1.1 现状

当前 `scripts/run_pipeline.py` 是**单次执行脚本**，执行流程：

```
asyncio.run(main())  → 执行一次 → 退出
```

系统每次运行都从头初始化所有组件，采集一批数据后退出，**无法实现持续运营**。

### 1.2 需求目标

根据需求设计，系统应实现：

| 功能 | 描述 |
|------|------|
| **常态化巡逻** | 后台 24/7 不间断运行，持续从各渠道拉取数据 |
| **增量采集** | 每次只采集新数据，不重复处理已入库数据 |
| **黑话自学习** | slang learning 常态化，候选词状态自动流转 |
| **自进化闭环** | LLM 抽检 + 模型重训自动化 |

### 1.3 分步策略

完整实现工程量大，采用**分步推进**策略：

| 阶段 | 内容 | 优先级 |
|------|------|--------|
| **Phase 1** | 守护进程框架 + 定时采集循环 | 高 |
| **Phase 2** | slang learning 状态持久化 | 中 |
| **Phase 3** | LLM-as-a-Judge 每日抽检 | 低 |
| **Phase 4** | 模型重训触发与评估 | 低 |

## 3.4 浏览器按钮自动化

MediaCrawler 部分平台（小红书、快手等）需要登录后通过浏览器点击按钮触发采集。MediaCrawler 已提供 API（`POST /crawler/start`），但用户需要手动在浏览器点击。

**自动化方案**：通过 Chrome DevTools Protocol (CDP) 控制浏览器，自动点击按钮。

```python
"""
Browser Button Automation
使用 Chrome DevTools Protocol 自动点击 MediaCrawler 页面的开始按钮
"""
import asyncio
import logging
from typing import Optional

logger = logging.getLogger(__name__)


class BrowserAutomator:
    """
    通过 CDP 控制浏览器，自动点击 MediaCrawler 开始按钮
    """

    def __init__(self, ws_url: Optional[str] = None):
        self.ws_url = ws_url or "ws://127.0.0.1:9222/devtools/browser"
        self._browser = None
        self._page = None

    async def connect(self):
        """连接到本地 Chrome 浏览器"""
        from playwright.async_api import async_playwright
        self._playwright = async_playwright()
        await self._playwright.start()

        # 连接到已有浏览器（需要 Chrome 启动时加 --remote-debugging-port=9222）
        self._browser = await self._playwright.chromium.connect_over_cdp(self.ws_url)
        context = self._browser.contexts[0]
        self._page = context.pages[0] if context.pages else await context.new_page()

    async def click_start_button(self, timeout: int = 30000):
        """
        点击 MediaCrawler 页面上的开始按钮
        页面 URL 格式：http://127.0.0.1:PORT/crawler
        """
        if not self._page:
            await self.connect()

        # 查找并点击开始按钮
        try:
            # 尝试多种选择器
            selectors = [
                "button:has-text('开始')",
                "button:has-text('开始采集')",
                ".start-btn",
                "[class*='start']"
            ]
            for selector in selectors:
                try:
                    self._page.locator(selector).first.wait_for(timeout=5000)
                    await self._page.locator(selector).first.click()
                    logger.info(f"Clicked button: {selector}")
                    return True
                except Exception:
                    continue

            logger.warning("Could not find start button")
            return False
        except Exception as e:
            logger.error(f"Failed to click start button: {e}")
            return False

    async def close(self):
        """关闭连接"""
        if self._playwright:
            await self._playwright.stop()
```

**启动 Chrome**：
```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222

# Windows
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222

# Linux
google-chrome --remote-debugging-port=9222
```

**配置**：
```yaml

    enabled: true
    chrome_ws_url: "ws://127.0.0.1:9222/devtools/browser"
    click_on_start: true
```

## 3. Phase 1：守护进程框架 + 定时采集循环

### 3.1 新建文件

#### `services/daemon_scheduler.py`

基于 `asyncio` 的统一调度器，管理所有后台任务。

核心类：`DaemonScheduler`

```python
class DaemonScheduler:
    def __init__(self, config):
        self.config = config
        self._running = False
        self._tasks = []

    async def start(self): ...

    async def stop(self): ...

    async def _collection_loop(self):
        """每15分钟采集一次"""
        interval = self.config.daemon.get('collection_interval_seconds', 900)
        while self._running:
            try:
                await self._run_collection()
            except Exception as e:
                logger.error(f"Collection error: {e}")
            await asyncio.sleep(interval)

    async def _slang_evolution_loop(self): ...

    async def _run_collection(self):
        """执行一次采集流程（复用 run_pipeline.py 的逻辑）"""
        adapter = MediaCrawlerAdapter(self.config)
        await adapter.initialize()

        # 采集所有支持的平台
        all_messages = []
        for platform in ['douyin', 'tieba', 'xhs', 'ks', 'weibo']:
            messages = await adapter.poll_new_content(platform)
            all_messages.extend(messages)
            logger.info(f"Polled {len(messages)} messages from {platform}")

        if not all_messages:
            logger.warning("No messages polled from any platform")
            await adapter.finalize()
            return

        cleaned_messages = Cleaner().clean(all_messages)
        # ... 后续流水线处理
        await adapter.finalize()
```

**关键设计**：
- 各调度任务独立，互不影响
- 单个任务异常被捕获，不影响其他任务
- 信号处理（SIGTERM/SIGINT）优雅停止
- `asyncio.create_task()` 管理并发任务

#### `scripts/run_daemon.py`

守护进程入口脚本：

```python
async def main():
    config = get_config()
    scheduler = DaemonScheduler(config)

    loop = asyncio.get_event_loop()
    for sig in (signal.SIGTERM, signal.SIGINT):
        loop.add_signal_handler(sig, lambda: asyncio.create_task(scheduler.stop()))

    await scheduler.start()

    while scheduler._running:
        await asyncio.sleep(1)

if __name__ == '__main__':
    asyncio.run(main())
```

```python
    def __init__(self, config, slang_mappings=None):
        # ... 现有逻辑 ...

        # 新增：从 DB 恢复候选词状态
        self._load_candidates_from_db()

    def _load_candidates_from_db(self):
        """从 slang_candidates 表恢复候选词状态"""
        db = PostgreSQLService.get_instance()
        db_candidates = db.get_all_slang_candidates()
        for db_c in db_candidates:
            self._candidates[db_c.candidate_word] = SlangCandidate(
                word=db_c.candidate_word,
                contexts=[],  # 上下文不恢复，只恢复状态
                occurrence_count=db_c.occurrence_count,
                status=db_c.status,
                inference_count=db_c.inference_count,
                regex_pattern=db_c.regex_pattern,
                meaning=db_c.meaning,
                source_channel=db_c.source_channel
            )

    def _persist_candidate(self, candidate: SlangCandidate):
        """持久化候选词到 DB"""
        db_candidate = DBSlangCandidate(
            candidate_word=candidate.word,
            contexts=[text for _, text in candidate.contexts],
            occurrence_count=candidate.occurrence_count,
            status=candidate.status,
            inference_count=candidate.inference_count,
            regex_pattern=candidate.regex_pattern,
            meaning=candidate.meaning,
            source_channel=candidate.source_channel
        )
        pg_db.upsert_slang_candidate(db_candidate)
```

```python
        1. 从 clues 表采样高置信度样本 (confidence >= 0.9)
```

```python
async def _error_book_loop(self):
    """每日凌晨2AM执行 LLM 抽检"""
    check_hour = self.config.daemon.get('error_book_check_hour', 2)
    while self._running:
        now = datetime.now()
        # 计算下次执行时间
        next_run = now.replace(hour=check_hour, minute=0, second=0, microsecond=0)
        if now.hour >= check_hour:
            next_run += timedelta(days=1)

        sleep_seconds = (next_run - now).total_seconds()
        await asyncio.sleep(sleep_seconds)

        try:
            sampler = ErrorBookSampler()
            count = await sampler.sample_and_judge()
            logger.info(f"Error book sampling: {count} inconsistencies found")
        except Exception as e:
            logger.error(f"Error book sampling error: {e}")
```

```python
class ModelRetrainer:
    """自动化模型重训触发"""

    async def check_and_trigger(self) -> bool:
        """
        检查是否需要重训
        条件：silver_sample_count + platinum_sample_count >= threshold (默认2000)
        Returns: 是否触发了重训
        """
        db = PostgreSQLService.get_instance()

        silver_count = db.count_silver_samples()
        platinum_count = db.count_platinum_samples()
        total = silver_count + platinum_count

        threshold = self.config.auto_evolution.get('retrain_trigger_threshold', 2000)

        if total < threshold:
            logger.info(f"Retrain check: {total} samples (need {threshold})")
            return False

        logger.info(f"Retrain threshold reached: {total} samples, triggering retrain")

        db.update_evolution_status(RetrainStatus.QUEUED)
```

## 9. 风险与注意事项

| 风险 | 缓解措施 |
|------|---------|
| Token 消耗过高 | 仅输出警告日志，不限制使用；用户自行监控 |
| MediaCrawler 限流 | 已有 `_last_check_time` 控制请求频率 |
| 进程异常退出 | systemd 重启策略 + 异常日志记录 |
| 数据库连接泄漏 | 使用 context manager (`with db._get_cursor()`) |
| 小红书/快手需登录 | 浏览器自动化方案，但需确保登录状态有效 |
