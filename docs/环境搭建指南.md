## 1. 系统概述

本系统需要以下基础设施组件：

| 组件 | 用途 | 建议规格 |

## 2. MongoDB 安装与配置

### 2.1 安装（Ubuntu 20.04/22.04）

```bash
# 添加MongoDB官方源
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | tee /etc/apt/sources.list.d/mongodb-org-7.0.list
apt update

# 安装
apt install -y mongodb-org

# 启动服务
systemctl enable mongod
systemctl start mongod

# 验证
mongosh --eval "db.adminCommand('ping')"
```

### 2.2 用户与权限配置

```javascript
// 连接MongoDB
mongosh admin

// 创建管理员用户
db.createUser({
  user: "antiblack_admin",
  pwd: "YOUR_SECURE_PASSWORD",
  roles: [
    { role: "readWriteAnyDatabase", db: "admin" },
    { role: "userAdminAnyDatabase", db: "admin" }
  ]
})

// 创建应用数据库和用户
use antiblack
db.createUser({
  user: "antiblack_app",
  pwd: "YOUR_APP_PASSWORD",
  roles: [
    { role: "readWrite", db: "antiblack" },
    { role: "read", db: "antiblack" }
  ]
})
```

### 2.3 关键配置参数

编辑 `/etc/mongod.conf`：

```yaml
storage:
  dbPath: /var/lib/mongodb
  journal:
    enabled: true

systemLog:
  destination: file
  logAppend: true
  path: /var/log/mongodb/mongod.log

net:
  port: 27017
  bindIp: 0.0.0.0  # 允许远程访问，生产环境建议限制IP

operationProfiling:
  mode: slowOp
  slowOpThresholdMs: 100
```

### 2.4 建议的Collection设计

```
Database: antiblack

Collections:
  - entities              # 实体主表
  - message_refs          # 消息引用表
  - slang_mappings        # 黑话映射表

  - queries              # 查询任务表

  - exports              # 导出任务表
  - channels             # 渠道配置表
  - metrics              # 监控指标表
  - auto_evolution       # 自进化状态表
```

## 3. Kafka 集群安装与配置

### 3.1 环境要求

- Java 11+
- 内存建议 4GB+
- 磁盘建议 100GB+ SSD

### 3.2 安装（Zookeeper模式，简化版）

```bash
# 下载Kafka
cd /opt
wget https://downloads.apache.org/kafka/3.7.0/kafka_2.13-3.7.0.tgz
tar -xzf kafka_2.13-3.7.0.tgz
ln -s kafka_2.13-3.7.0 kafka
rm kafka_2.13-3.7.0.tgz

# 添加环境变量
echo 'export KAFKA_HOME=/opt/kafka' >> /etc/profile
echo 'export PATH=$PATH:$KAFKA_HOME/bin' >> /etc/profile
source /etc/profile
```

### 3.3 Topic创建（支持回溯）

**关键设计**：Kafka消息保留7天，确保任意时间范围的回溯需求。

```bash
# 创建Topic - 使用较大partition数和较长保留期
KAFKA_HOME/bin/kafka-topics.sh --create --bootstrap-server localhost:9092 \
  --topic raw.messages --partitions 10 --replication-factor 1 \
  --config retention.ms=604800000 \      # 7天保留
  --config max.message.bytes=10485760

KAFKA_HOME/bin/kafka-topics.sh --create --bootstrap-server localhost:9092 \
  --topic cleaned.messages --partitions 10 --replication-factor 1 \
  --config retention.ms=604800000

KAFKA_HOME/bin/kafka-topics.sh --create --bootstrap-server localhost:9092 \
  --topic deep.analysis.tasks --partitions 5 --replication-factor 1 \
  --config retention.ms=604800000

KAFKA_HOME/bin/kafka-topics.sh --create --bootstrap-server localhost:9092 \
  --topic image.analysis.tasks --partitions 5 --replication-factor 1 \
  --config retention.ms=604800000

# 验证
KAFKA_HOME/bin/kafka-topics.sh --list --bootstrap-server localhost:9092
```

### 3.4 Topic说明

| Topic | 用途 | 保留时间 | 分区数 |
|-------|------|----------|--------|
| raw.messages | 原始消息采集 | 7天 | 10 |
| cleaned.messages | 清洗后消息 | 7天 | 10 |
| deep.analysis.tasks | 深度分析任务 | 7天 | 5 |
| image.analysis.tasks | 图片分析任务 | 7天 | 5 |

## 4. LightRAG 及其存储后端配置

### 4.1 Neo4j 安装（作为Graph Storage）

```bash
# 添加Neo4j源
wget -O - https://debian.neo4j.org/neotechnology.gpg.key | apt-key add -
echo 'deb https://debian.neo4j.org stable latest' > /etc/apt/sources.list.d/neo4j.list
apt update

# 安装Neo4j
apt install -y neo4j-5

# 配置
nano /etc/neo4j/neo4j.conf
# 修改以下配置：
# dbms.connector.http.listen_address=0.0.0.0:7474
# dbms.connector.bolt.listen_address=0.0.0.0:7687
# dbms.memory.heap.initial_size=2g
# dbms.memory.heap.max_size=4g

# 启动
systemctl enable neo4j
systemctl start neo4j

# 验证
cypher-shell -u neo4j -p neo4j "RETURN 1"
```

### 4.2 PostgreSQL 安装（作为向量存储 + LightRAG向量后端）

```bash
# 安装
apt install -y postgresql postgresql-contrib

# 启动
systemctl enable postgresql
systemctl start postgresql

# 创建数据库和用户
su - postgres
psql << EOF
CREATE USER antiblack WITH PASSWORD 'YOUR_DB_PASSWORD';
CREATE DATABASE antiblack OWNER antiblack;
CREATE EXTENSION IF NOT EXISTS vector;
GRANT ALL PRIVILEGES ON DATABASE antiblack TO antiblack;
EOF
```

### 4.3 LightRAG 安装

```bash
# 创建工作目录
mkdir -p /opt/antiblack
cd /opt/antiblack

# 克隆LightRAG（用户已在本地克隆，复制过去）
# cp -r /path/to/local/LightRAG /opt/antiblack/

# 或者直接git clone
git clone https://github.com/HKUDS/LightRAG.git
cd LightRAG

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装LightRAG及依赖
pip install -e ".[test,offline,api]"

# 验证安装
python -c "from lightrag import LightRAG; print('LightRAG OK')"
```

### 4.4 环境变量配置

在 `/opt/antiblack/LightRAG/.env` 配置：

```bash
# ===================
# LLM 配置 (OpenAI兼容接口)
# ===================
OPENAI_API_BASE=https://api.openai.com/v1
OPENAI_API_KEY=your_api_key_here
LLM_MODEL=gpt-4o-mini
EMBEDDING_MODEL=text-embedding-3-small

# ===================
# LightRAG 存储后端
# ===================
GRAPH_STORAGE=Neo4jStorage
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your_neo4j_password

VECTOR_STORAGE=PGVectorStorage
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_USER=antiblack
POSTGRES_PASSWORD=YOUR_DB_PASSWORD
POSTGRES_DATABASE=antiblack

KV_STORAGE=PGKVStorage

# ===================
# MongoDB 配置
# ===================
MONGODB_URI=mongodb://antiblack_app:YOUR_APP_PASSWORD@localhost:27017/antiblack

# ===================
# Kafka 配置
# ===================
KAFKA_BOOTSTRAP_SERVERS=localhost:9092
```

## 7. 服务自启动配置

### 7.1 Systemd 服务文件

创建 `/etc/systemd/system/antiblack-api.service`：

```ini
[Unit]
Description=AntiBlack API Server
After=network.target mongod.service neo4j.service postgresql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/antiblack
Environment=PATH=/opt/antiblack/venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
ExecStart=/opt/antiblack/venv/bin/python -m uvicorn api.server:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 7.2 启用服务

```bash
systemctl daemon-reload
systemctl enable antiblack-api
systemctl start antiblack-api
```

## 8. 常见问题排查

### 8.1 MongoDB 连接失败
```bash
# 检查服务状态
systemctl status mongod

# 检查端口
nc -zv localhost 27017

# 查看日志
tail -f /var/log/mongodb/mongod.log
```

### 8.2 Kafka Topic 创建失败
```bash
# 确认Java已安装
java -version

# 检查Zookeeper状态
systemctl status zookeeper

# 查看Kafka日志
tail -f $KAFKA_HOME/logs/server.log
```

### 8.3 LightRAG 存储后端连接问题
```bash
# Neo4j认证问题 - 修改初始密码
cypher-shell -u neo4j -p neo4j "CALL dbms.changePassword('newPassword')"

# PostgreSQL vector扩展
PGPASSWORD=YOUR_DB_PASSWORD psql -d antiblack -c "CREATE EXTENSION IF NOT EXISTS vector"
```
