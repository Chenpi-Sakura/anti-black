# 黑灰产情报分析Agent系统 UI设计规范

**版本**：V1.0
**日期**：2026-05-23
**设计风格**：低磅线条 + 衬线体 + 蓝调主色

---

## 1. 设计语言

### 1.1 视觉关键词

| 关键词 | 说明 |
|--------|------|
| **轻盈** | 大量细线条(1px/0.5px)，留白充足，呼吸感强 |
| **克制** | 色彩极度克制，主色#0000FF统领全局 |
| **秩序** | 衬线体带来的经典秩序感，严谨但不冰冷 |
| **透明** | 半透明叠加、细线分割，信息层次清晰 |

### 1.2 字体规范

**西文衬线体**：
- 标题：`Playfair Display` / `Georgia`（备选）
- 正文：`Crimson Text` / `Times New Roman`（备选）

**中文字体**：
- 标题：`思源宋体`（Source Han Serif CN）
- 正文：`思源宋体` / `Noto Serif SC`
- 等宽/代码：`JetBrains Mono` / `Consolas`

**字号层级**：
| 层级 | 字号 | 字重 | 说明 |
|------|------|------|------|
| H1 | 28px | 400 | 页面主标题 |
| H2 | 20px | 500 | 区块标题 |
| H3 | 16px | 500 | 子区块标题 |
| Body | 14px | 400 | 正文内容 |
| Caption | 12px | 400 | 辅助说明 |
| Mono | 13px | 400 | 代码/数据 |

### 1.3 线条规范

| 类型 | 粗细 | 颜色 | 用途 |
|------|------|------|------|
| 主分割线 | 1px | `rgba(0, 0, 255, 1)` | 主要区块分割 |
| 次分割线 | 0.5px | `rgba(0, 0, 255, 0.4)` | 子区块分割 |
| 装饰线 | 0.5px | `rgba(0, 0, 255, 0.2)` | 标题下划线 |
| 边框线 | 0.5px | `rgba(0, 0, 255, 0.3)` | 卡片/输入框边框 |
|hover/active线 | 1px | `rgba(0, 0, 255, 1)` | 交互状态 |

> **颜色格式**：统一使用 `rgba()` 格式。例如 `#0000FF @ 40%` → `rgba(0, 0, 255, 0.4)`。

### 1.4 间距系统

基于 `8px` 网格：
- `xxs`: 4px
- `xs`: 8px
- `sm`: 16px
- `md`: 24px
- `lg`: 32px
- `xl`: 48px
- `xxl`: 64px

## 9. 动画规范

### 10.1 贝塞尔曲线预设

所有动画均使用三次贝塞尔曲线，确保流畅高级的动效体验：

> **CSS 兼容性**：以下动画属性建议添加 `-webkit-` 前缀以兼容 Safari/iOS。生产环境可使用 PostCSS 插件（如 `autoprefixer`）自动处理。
> - `animation` → `-webkit-animation`
> - `transform` → `-webkit-transform`
> - `transition` → `-webkit-transition`
> - `box-shadow` → `-webkit-box-shadow`

| 曲线名称 | 参数 | 适用场景 |
|---------|------|----------|
| **ease-out-quint** | `cubic-bezier(0.22, 1, 0.36, 1)` | 元素进入、快速停止 |
| **ease-in-quint** | `cubic-bezier(0.64, 0, 0.78, 0)` | 元素退出、快速启动 |
| **ease-in-out-quint** | `cubic-bezier(0.86, 0, 0.07, 1)` | 元素状态切换、对称动画 |
| **spring** | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹跳效果、强调反馈 |
| **smooth-step** | `cubic-bezier(0.65, 0, 0.35, 1)` | 阶段切换、进度更新 |
| **gentle** | `cubic-bezier(0.4, 0, 0.2, 1)` | 常规过渡（默认） |

### 10.2 时长规范

| 类型 | 时长 | 适用场景 |
|------|------|----------|
| **即时** | 100ms | 颜色变化、hover反馈 |
| **快速** | 200ms | 按钮状态切换、输入框焦点 |
| **标准** | 300ms | 卡片展开、阶段切换 |
| **舒缓** | 400ms | 页面元素入场 |
| **慢速** | 600ms | 复杂动画、弹窗 |
| **戏剧性** | 800ms | 重要结果展示 |

### 10.3 入场动画

**元素整体入场（fade + slide）**：
```css
animation: fadeSlideIn 400ms ease-out-quint both;
@keyframes fadeSlideIn {
  from {
    opacity: 0;
    transform: translateY(12px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

**交错入场（stagger）**：
```css
/* 每个子元素延迟 80ms 入场 */
animation: fadeSlideIn 400ms ease-out-quint both;
animation-delay: calc(var(--index) * 80ms);
```

**进度条填充**：
```css
/* 从左到右，贝塞尔曲线 */
animation: progressFill 600ms ease-out-quint both;
@keyframes progressFill {
  from { transform: scaleX(0); }
  to { transform: scaleX(1); }
}
```

### 10.4 阶段卡片动画

**卡片展开**：
```css
/* 高度展开 + 内容淡入 */
.card-expand {
  animation: cardExpand 400ms ease-out-quint both;
}
@keyframes cardExpand {
  from {
    opacity: 0;
    max-height: 80px;
    padding: 16px 24px;
  }
  to {
    opacity: 1;
    max-height: 400px;
    padding: 20px 24px;
  }
```
