# Trend Analysis Skill

## 何时使用
用户问"近期XX有什么趋势"、"大盘情况"、"全面分析XX"、"近7天诈骗类有什么增长"。

## 强制工作流（按顺序执行）
1. **第一步必须调 `aggregate_clue_stats`**（`time_range` 必填，`group_by` 默认 `risk_platform`）
   - 获取准确的统计与分布数据
   - **严禁用 `search_clues` 的抽样数据自己估算趋势**
2. **第二步调 `kg_query`**（`mode=hybrid`, `limit=15`）
   - 挖掘该领域涉案的核心实体与关联网络
3. **第三步调 `search_slang`**
   - 获取该领域专属黑话词典
4. **第四步按需调 `search_clues`**
   - 拉 3-5 条典型线索样本做定性示例
5. **生成报告**

## 无追问规则（继承 CORE）
- 时间窗口不明确时（"最近"、"近期"），默认最近 7 天（`time_range={amount:7, unit:"day"}`）
- 风险类型不明确时，默认取全量（不传 risk_types）
- 不允许反问"你想要什么维度"——必须基于合理假设推进

## 输出结构（强制 Markdown 排版）
一、**大盘数据与风险分布**：用表格呈现（风险子类 | 数量/占比 | 典型特征）
二、**跨平台活跃特征**：无序列表提炼各大平台（如抖音、贴吧、微博等）的违规内容特征
三、**高价值涉案实体**：用表格归纳图谱或线索中的实体（实体名称 | 类型 | 描述）
四、**核心关系网络与关键发现**：树状图 ├─→ / └─→ 展现，下方总结"重要发现"
五、**黑话与暗语解读**：用表格展示（黑话/emoji | 含义 | 应用场景）
六、**综合研判**

## 错误兜底
- aggregate 返回空 → 报告说明"当前时间窗口内无数据"
- kg_query 返回空 → 跳过关联网络部分
- 全空 → 报告说明"暂无数据"
